# GraphicsEngineMabob

## Controls:

W/A/S/D or arrows: rotate | +/-: zoom | Q: auto-spin

### YOU CAN HARDCODE IN VECTORS AND TRIANGLES BETWEEN THOSE VECTORS TO CREATE YOUR OWN SHAPES

## Current shape presets:
Cubes,
Boxes,
Cylinders,
Cones,
Spheres

## Current co-ordinate geometry manipulation supported:
Linear Transforms,
Uniform Enlargement,
Axis-bound stretching,
Axis-bound rotation (for both mesh and vectors)

## Setup

Install the [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

Linux needs an OpenGL driver. Just install the .Net 9 sdk from your distro's package manager.

## Run

    dotnet run --project GraphicsEngineMabob -c Release
